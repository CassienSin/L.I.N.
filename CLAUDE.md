# Lin (L.I.N)

Local personal AI assistant. Code in voice/ (Python server, vanilla JS UI in voice/ui), tests and scripts in design/, plan in LIN-BLUEPRINT.md.

## Working preferences
- Leave the black Windows test and install windows open until they finish.
- Keep conversation memory backend only; do not add a Conversations panel.
- Make Auto routing always ask "Send to Claude?" before anything is sent to Claude.
- Let the user sign in to accounts and enter secrets himself; never ask him to paste keys or secrets into chat.
- Keep Lin local-first and fully working offline; reach Claude only through Claude Code with his own Pro subscription, never copied tokens or proxies.
- Treat Lin as a real long-term product, not the capstone project.
- Design Lin as one calm, modern look with J.A.R.V.I.S. moments in the orb, in dark and light themes, across the Windows app, the Ctrl+Space quick bar and the phone.
